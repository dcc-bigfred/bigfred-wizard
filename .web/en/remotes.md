# Supported handsets

wiFred and LongFred handsets are programmed fully automatically, with no need to type the WiFi password. Switch the handset on and press the key combination that puts it into programming mode, and Wizard finds it on its own.

Classic wired FREDi handsets are programmed through the LocoNet socket provided by a command station with a programming track over the Z21 protocol.

Other handsets that speak wiThrottle or Z21, and are not listed above, should work as well. Configuring them means typing the network name, the WiFi password and pairing with BigFred using a PIN.

The Roco Z21 WlanMaus is an example of a handset that works without trouble, but setting it up is not simple. Every value has to be entered by hand, because that is all the manufacturer allows. There is no automatic setup: we cannot change the software of this commercial handset.
