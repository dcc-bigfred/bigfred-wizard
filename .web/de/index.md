# BigFred Wizard

Stell ein Tablet auf den Tisch. Mit BigFred Wizard kann jeder Gast sich ein Konto anlegen, eine Lokadresse programmieren, einen Handregler koppeln oder die App auf dem Telefon einrichten.

Ein paar Klicks reichen für die Grundlagen, damit man fahren kann. Die erweiterten Funktionen stecken in der App auf dem Telefon.

## Was erledigen die Gäste am Tablet mit Wizard?

- Sie legen sich ein Benutzerkonto an
- Sie fügen ein Fahrzeug mit automatisch vergebener DCC-Adresse hinzu
- Sie programmieren die Adresse im Fahrzeug, indem sie es aus der Liste wählen
- Sie koppeln einen drahtlosen Handregler mit dem System, **ohne das WLAN-Passwort einzugeben! Wizard erkennt den eingeschalteten Regler und trägt die WLAN-Zugangsdaten selbst ein**
- Wer FREDi benutzt, kann mit ein paar Klicks eine beliebige DCC-Adresse eintragen
